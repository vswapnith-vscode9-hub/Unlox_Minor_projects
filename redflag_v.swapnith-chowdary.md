# RedFlag – Fraud Detection Project

## Project Overview

RedFlag is a SQL-based fraud detection project designed to identify suspicious financial transactions.

The project analyzes transaction data and looks for unusual patterns that may indicate fraudulent activity.

## Objectives

- Identify suspicious transactions.
- Analyze unusual transaction amounts.
- Detect frequent or repeated transactions.
- Identify transactions made from different locations within a short period.
- Analyze transaction timing and customer behavior.
- Generate useful results for fraud investigation.

## Technologies Used

- MySQL
- SQL
- MySQL Workbench

## Project Structure

The project contains SQL queries for:

1. Creating the required database and tables.
2. Loading and preparing transaction data.
3. Cleaning and analyzing the data.
4. Identifying suspicious transactions.
5. Detecting unusual transaction patterns.
6. Generating fraud investigation results.

## Fraud Detection Analysis

The project checks different red-flag patterns such as:

- High-value transactions
- Multiple transactions within a short time
- Transactions from different cities within a short time
- Unusual transaction frequency
- Suspicious transaction behavior

## How to Run the Project

1. Install MySQL and MySQL Workbench.
2. Open MySQL Workbench.
3. Connect to the MySQL server.
4. Open the SQL project file.
5. Select the required database/schema.
6. Execute the SQL queries using the Execute button.
7. Check the output and query results.

## Expected Outcome

The project produces SQL query results that help identify transactions with suspicious characteristics and potential fraud risk.

## Conclusion

The RedFlag project demonstrates how SQL can be used to analyze financial transaction data and identify patterns that may indicate fraudulent activity. It provides a practical approach to fraud investigation using data analysis and SQL queries.
