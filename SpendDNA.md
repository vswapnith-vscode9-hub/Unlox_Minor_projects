# SpEnDNA – Minor Project

SpEnDNA is a project based on DNA sequence analysis.

## About the Project

- This project works with DNA sequences.
- It helps to understand and analyze DNA data.
- We use computational methods to study the sequences.
- The project shows how technology can be used in biological research.

## Technologies Used

- Python
- Bioinformatics
- DNA Sequence Analysis

## Conclusion

This project helped us understand DNA sequences and how computational tools can be used to analyze biological data.
